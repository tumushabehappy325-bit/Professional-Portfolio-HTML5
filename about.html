Terms I use

Semantic HTML
Markup chosen for what content means, such as a heading, a list or a navigation area, rather than how it looks.
Landmark
An element like header, nav or main that lets screen reader users jump straight to a region of the page.
Alt text
A short written description of an image, read aloud when the image cannot be seen or fails to load.
Wireframe
A plain sketch of a page layout that shows where content goes before any colour or type is chosen.
Sitemap
A diagram of every page in a site and how the pages link together.
Commit
A saved snapshot of the project in Git, with a message that says what changed.
Hyperlink
Text or an image that takes the visitor to another page, or to another place on the same page.
